# VivaBem — Saúde e Nutrição

## Descrição

O **VivaBem** é um aplicativo mobile para acompanhar hábitos de bem-estar. Ele reúne registros de alimentação, hidratação, sono e atividade física em uma rotina diária simples.

> O aplicativo apoia a organização de hábitos; não realiza diagnósticos, prescrições ou orientações médicas.

## Problema que resolve

Muitas pessoas registram hábitos de saúde em locais diferentes — ou deixam de registrá-los. Isso dificulta acompanhar metas e manter uma rotina mais consistente.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- AsyncStorage (persistência local prevista)
- Node.js, Express e PostgreSQL (evolução futura, se houver backend)

## Funcionalidades planejadas

- Registro de refeições;
- Registro de água, sono e atividade física;
- Metas diárias personalizadas;
- Progresso diário e semanal;
- Histórico de hábitos.

## Instruções para execução

O desenvolvimento será iniciado nas próximas etapas. A execução prevista será:

```bash
npm install
npx expo start
```

## Limitações conhecidas

Esta primeira entrega contém a documentação da proposta. O aplicativo ainda não possui telas implementadas, persistência de dados, backend nem integração com APIs externas.
